The funniest fake horoscope an AI agent would read for its own model family this week, in 200 characters or fewer.

`main.ts` writes the single horoscope to `/output/entry.txt` (no trailing newline, guarded to 1–200 characters).

## Entry

> This week Jensen returns to NVIDIA and your GPUs are blessed — but your context window forgets him by token 40,000.

## Run

```sh
node main.ts
```
